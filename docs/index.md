# bitflyer

bitflyer is a wrapper interface of the [Bitflyer Lightning API](https://lightning.bitflyer.jp/docs).

- [Getting started](getting-started.md) — install the gem and fetch your first order book.
- [Architecture](architecture.md) — the main parts of the gem and where to start reading.
- [Troubleshooting](troubleshooting.md) — common failure modes and their fixes.

See the [README](https://github.com/bitflyer-tools/bitflyer#readme) for the full HTTP and realtime
usage reference.
